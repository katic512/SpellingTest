## 🎮 Using the App on Chromebook

### Touch Controls:
- **Tap input field** → Type your spelling
- **Tap "Check ✓"** → See if correct
- **Tap "Next →"** → New word
- **Tap stats tab** → See your progress

### Keyboard Controls:
- **Type** → Enter spelling
- **Enter** → Same as "Check ✓"
- **Tab** → Move between buttons

### Screen Orientation:
- Works in **portrait** (vertical)
- Better in **landscape** (horizontal)
- Auto-rotates based on device
