Go to: https://console.neon.tech2. Select your project3. Go to: **Connection String** or **Connection strings**4. Copy the full PostgreSQL URL5. Paste into Vercel**Variable 2: JWT_SECRET**```Name:        JWT_SECRETValue:       [Random 32-character string]Environment: Production, Preview, Development```Generate random secret:```bashnode -e "console.log(require('crypto').randomBytes(32).toString('hex'))"```Copy output and paste into Vercel.**Variable 3 (Optional): MERRIAM_WEBSTER_API_KEY**```Name:        MERRIAM_WEBSTER_API_KEYValue:       [Your API key or leave blank for default]Environment: Production, Preview, Development```### Step 2: Verify DeploymentAfter setting env vars:1. **Automatic Redeploy**:   - Vercel may automatically redeploy (check Deployments tab)   - Or manually trigger:     - Deployments → Latest → Redeploy button2. **Wait for Build**:   - Status should change to: `Building` → `Built` → `Ready`   - Takes 3-5 minutes typically3. **Check Build Logs** (if issues):   - Click latest deployment   - Scroll to "Build Logs"   - Look for error messages### Step 3: Test Endpoints**Health Check**:```bashcurl https://spelling-test-kappa.vercel.app/api/health```Response: `{"ok":true}`**Get Words**:```bashcurl https://spelling-test-kappa.vercel.app/api/words```Response: `{"words":["word1","word2",...]}` or error if no words**Register User**:```bashcurl -X POST https://spelling-test-kappa.vercel.app/api/auth/register \  -H "Content-Type: application/json" \  -d '{"username":"testuser","password":"test123456"}'```Response:```json{  "token": "eyJ...",  "user": {"id": 1, "username": "testuser", "role": "user"}}```**Login**:```bashcurl -X POST https://spelling-test-kappa.vercel.app/api/auth/login \  -H "Content-Type: application/json" \  -d '{"username":"testuser","password":"test123456"}'```Same response format as register.### Step 4: Test in Browser1. Open: https://spelling-test-kappa.vercel.app/2. Try to login or register3. (Check Deployments tab for "Ready")4. ✓ Tried hard refresh? (**Cmd+Shift+R** Mac, **Ctrl+Shift+R** Windows)### Issue: Database Connection Error**Check**:- DATABASE_URL value is correct (copy from Neon again)- Includes full password and connection details- Starts with `postgresql://`- Uses `:` between user and password, not `@`- Format: `postgresql://user:password@host/database?sslmode=require`### Issue: JWT Authentication Failing**Check**:- JWT_SECRET is set and is a string- All characters copied correctly- No spaces at beginning or end### Issue: Functions Not Showing in VercelIn Vercel Dashboard → Your Project → **Functions** tab:- Should see: `api/index.ts`- Status should be: `Ready`If not there:- Check vercel.json exists in project root- Check api/index.ts exists- Check Build Logs for errors- Try manual redeploy### Issue: Build Failed**Check build logs**:1. Vercel Dashboard → Deployments2. Click latest deployment3. Scroll to "Build Logs"4. Look for specific error message5. Common causes:   - Missing npm dependencies   - TypeScript compilation error   - Environment variable not set correctly---## 🔒 Security Best Practices✅ **Already Implemented**:- CORS enabled for Vercel domain- JWT authentication on protected routes- Password hashing with bcrypt- SQL injection prevention (parameterized queries)- Environment variables for secrets (not hardcoded)- Admin role separation**What to Keep Secure**:- Never share JWT_SECRET- Never commit .env file- Keep DATABASE_URL private- Regenerate JWT_SECRET if compromised---## 📈 Performance| Metric | Value | Notes ||--------|-------|-------|| First API call | 1-2 sec | Cold start (first request) || Subsequent calls | <100ms | Warm functions || Frontend load | 500ms | CDN cached || Database query | <10ms | Neon optimized || API quota | 100 calls/mo | vs 15,000 without caching |---## 🆘 Getting Help### Quick Reference- **Functions not showing**: Check vercel.json routing config- **Build errors**: Check build logs in Vercel dashboard- **Database issues**: Check DATABASE_URL env var- **Auth issues**: Check JWT_SECRET env var### Documentation- `DEPLOYMENT_CHECKLIST.md` - One-page checklist- `QUICK_FIX_404.md` - Action steps- `VERCEL_FIX_SUMMARY.md` - Architecture overview- `DEPLOY_NOW.md` - Quick start guide### Manual Redeploy
