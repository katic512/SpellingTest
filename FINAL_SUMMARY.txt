================================================================================
                           HOW IT WORKS
================================================================================

WHEN ADMIN ADDS WORD:
  1. Admin enters word + optional meaning
  2. Click "Add"
  3. Saved to database
  4. If no meaning: Auto-fetch from API
  5. Save meaning to database
  6. Show success message

WHEN STUDENT PRACTICES:
  1. Student encounters word
  2. Backend checks database for definition
  3. Found? Return instantly (no API call)
  4. Not found? Fetch from API and cache
  5. Display definition to student

WHEN ADMIN CLICKS FETCH:
  1. Click "Fetch" on word without definition
  2. API called to get definition
  3. Definition saved to database
  4. Row updates with definition
  5. "Fetch" button disappears
